= antora-facto
:description: De-facto Antora playbook composition — Valentus UI plus search, math, diagrams, and page-context metadata. Not Valentus core.

*antora-facto* is the **compose pack** for a sensible Antora site stack.
It documents and templates what DevCentr / antora-supplemental already reuse together:

* **Valentus** UI bundle (`v2` rolling tag) — lean theme only
* **Lunr** (`@antora/lunr-extension`) — site search
* **STEM / KaTeX** — `stem: latexmath` (+ supplemental math JS/CSS until in-bundle)
* **Kroki diagrams** (`asciidoctor-kroki`) — Mermaid + PlantUML → SVG at build time
* **Page context** (`@antora-supplemental/page-context`) — audience / author / rights metadata from `page-*` attributes
* Optional neighbors: alias-to-latest / unversioned component URLs, search-chat omnibox, **site-nav-tree** (multi-component sidebar forest with an **`include` allowlist**; keeps default nav-tree)
* Playbook default: `urls.html_extension_style: indexify` (folder URLs; `index.adoc` → trailing-slash path)

Wiring a product repo under `content.sources` publishes pages and xrefs — it does **not** mean the component belongs in the sidebar forest. Thin tools: hub portal under `home` only, or register the source but omit it from site-nav-tree `include`.

== Why a separate pack (not Valentus “full”)

Valentus stays lightweight so theme-only adopters are not scared off.
Facto is discovered **by pack name** (like a VS Code extension pack): theme + the other extensions you usually want, without folding those extras into Valentus core.

== Quick start

. Copy `playbook.fragment.yml` into your playbook (or start from `examples/minimal-playbook.yml`).
. `pnpm add antora @antora/lunr-extension asciidoctor-kroki @antora-supplemental/page-context`
+
Until page-context is on npm: `pnpm add github:antora-supplemental/page-context#main`
. Point `ui.bundle.url` at the Valentus `v2` release zip.
. Add brand/math/mermaid supplemental files as needed (see Valentus docs / org `supplemental-ui` patterns).

CI needs network access to `kroki-server-url` during `antora` when `kroki-fetch-diagram: true` (or self-host Kroki).

The fragment sets `page-context-active` so page bodies can keep `ifndef::page-context-active[]` fallbacks that stay hidden under Facto.

== Not in scope

* Changing Valentus default `v2` to force Lunr/Kroki/math/page-context
* Replacing Antora itself
* A heavyweight monorepo of every antora-supplemental extension
